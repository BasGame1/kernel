# Lyncex Kernel

A lightweight kernel focused on security and compatibility


## Features

- Neo, a secure hypervisor for security operations
- Private Kcalls and SIDs, for improved security
- Antartica, a linux compatibility screen
- Microkernel arch, for isolation
- No reboot kernel updates
- A/B updates
- Less than 300kb
- Support for ARM, X86 and RISCV in 32 and 64 bit
- POSIX compliant
- Debug builtin shell, for debugging at boot
- Malware detection, via neo with a common malware hashes list
- Modules, support for linux and own modules
